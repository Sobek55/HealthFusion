# HealthFusion

HealthFusion is a web application designed to help users track nutrition,
manage meals, customize food choices, and monitor progress toward personal
health goals.

## Technology Stack

### Frontend
- React
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js

### Database
- MySQL

## Project Structure

- `frontend/` - React frontend
- `backend/` - Node.js / Express REST API
- `database/` - MySQL schema and database scripts
- `docs/` - Technical and design documentation

## Status

HealthFusion is currently under development.
